Project flow and testing guide
This file explains the complete project flow, login signup flow, manual testing sequence, and purpose of the main files.
Main application flow

The browser opens the home route.
HomeControl loads products and categories from ProductDao and CategoryDao.
HomeControl forwards to index.jsp.
The user can open the shop page.
ShopControl loads paginated products and categories.
ShopControl forwards to shop.jsp.
The user can click a product.
ProductDetail loads the selected product and forwards to product-detail.jsp.
The user can add a product to the cart.
CartControl stores the cart in the session as order and stores the total in the session as total_price.
The user can open cart.jsp to view or remove cart items.
The user can open checkout.jsp from the cart page.
CheckoutControl requires login before placing the order.
CheckoutControl updates account contact details, creates the order, creates order detail rows, reduces product stock, clears the cart session, and forwards to thankyou.jsp.
The customer can open order-history to see previous orders.
OrderHistoryControl loads the logged in customer orders and forwards to order-history.jsp.
The customer can open order-detail for one order.
orderDetailControl loads te product lines for that order and forwards to order-detail.jsp.
Seller and admin style flow
A logged in seller can open product-management.
ProductManagementControl loads the seller products and categories and forwards to product-management.jsp.
The seller can add a product from product-management.jsp.
AddProductControl receives the form, reads the uploaded image, and inserts the product through ProductDao.
The seller can edit a product.
EditProductControl loads the product and categories for edit-product.jsp, then updates the product on submit.
The seller can remove a product.
RemoveProductControl marks the product as deleted instead of physically deleting it.
The seller can open order-management.
OrderManagementControl loads order details for products owned by that seller and forwards to order-management.jsp.
Login flow
login.jsp displays the login form.
The form posts to login with status typed.
LoginControl reads username and password.
LoginControl calls AccountDao checkLoginAccount.
AccountDao checks the account table using a prepared statement.
If the account is not found, LoginControl forwards back to login.jsp with the alert Wrong username or password.
If the account is found, LoginControl stores the Account object in the session using the key account.
If remember me is checked, LoginControl stores username and password cookies for a short time.
After successful login, LoginControl redirects to the home route.
LogoutControl removes the account session attribute and clears the remember me cookies.
Signup flow
register.jsp displays the registration form.
The form posts to register using multipart form data because it can upload a profile image.
RegisterControl reads username, password, repeat password, and profile image.
RegisterControl rejects empty username or password.
RegisterControl checks that password and repeat password match.
RegisterControl calls AccountDao checkUsernameExists to prevent duplicate usernames.
AccountDao checks duplicate usernames using a prepared statement.
If validation fails, RegisterControl forwards back to register.jsp with an alert.
If validation passes, RegisterControl calls AccountDao createAccount.
AccountDao inserts the account into the account table.
After successful registration, RegisterControl forwards to login.jsp with a success message.
Profile flow
profile-page.jsp displays the logged in account details.
ProfileControl requires a logged in account.
ProfileControl updates first name, last name, address, email, phone, and optionally profile image.
If no new image is uploaded, ProfileControl keeps the existing image and only updates text fields.
After updating, ProfileControl refreshes the account object in the session and redirects back to profile-page.
How to test every feature
First prepare MySQL.
Create the veloct database.
Import Dump20210903.sql.
Confirm Database.java has the correct database name, username, and password.
Build the project with mvn clean package.
Deploy the WAR to a Jakarta compatible servlet container such as Tomcat 10.
Open the application home URL in the browser.
Test home page.
Open the root URL.
Expected result is index.jsp with product and category data visible.
If product cards are empty, check Database.java and the product table.
Test shop page.
Open shop.
Expected result is shop.jsp with product list, category list, and pagination.
Click a page number.
Expected result is the same shop page with products for that page.
Test category filter.
Open shop
Click a category
Expected result is category route forwarding to shop.jsp with only products from that category.
Test search.
Use the search box from the header if available.
Search for a product name from the database.
Expected result is search route forwarding to shop.jsp with matching products.
Search with an empty keyword.
Expected result is redirect back to shop.
Test product detail.
Open shop.
Click a product image or product name.
Expected result is product-detail.jsp with image, name, description, price, stock, quantity input, and add to cart button.
Open product-detail without an id.
Expected result is redirect to shop.
Test cart add.
Open a product detail page.
Enter quantity one.
Submit add to cart.
Expected result is redirect back to product detail and the session cart is updated.
Open cart.jsp.
Expected result is the product appears in the cart and total_price is shown.
Test invalid cart quantity.
Open a product detail page.
Enter a quantity higher than available stock.
Submit add to cart.
Expected result is redirect back to product detail with a stock warning.
Test cart remove.
Open cart.jsp after adding a product.
Click remove for one item.
Expected result is item removed and total_price updated.
Test checkout without login.
Add an item to the cart.
Open checkout.jsp and submit the checkout form while not logged in.
Expected result is redirect to login.
Test signup.
Open register.jsp.
Submit with different password and repeat password.
Expected result is Incorrect password alert.
Submit with an already existing username.
Expected result is Username already exists alert.
Submit with a new username and matching passwords.
Expected result is forward to login.jsp with Account created successfully.
Test login.
Open login.jsp.
Submit a wrong username or password.
Expected result is Wrong username or password alert.
Submit a correct username and password from the account table.
Expected result is redirect to home and account is saved in the session.
Test remember me.
Login with Remember me checked.
Close and reopen the browser quickly or open the app again before the cookie expires.
Expected result is automatic login from username and password cookies.
Click logout.
Expected result is account removed from session and remember me cookies cleared.
Test profile.
Login first.
Open profile-page.
Expected result is profile-page.jsp with account fields.
Edit profile fields without selecting a new image.
Expected result is text fields updated and old image remains.
Edit profile fields with a new image.
Expected result is text fields and image updated.
Open profile-page while logged out.
Expected result is redirect to login.
Test product management.
Login as an account that has seller products.
Open product-management.
Expected result is product-management.jsp with seller product rows and category dropdown data.
Submit the add product form with name, price, description, category, stock amount, and image.
Expected result is redirect back to product-management and new product appears.
Click edit for a product.
Expected result is edit-product.jsp with existing product data.
Submit changed product data.
Expected result is redirect back to product-management and updated values appear.
Click remove for a product.
Expected result is product status changes to deleted and it no longer appears in normal shop results.
Test order placement.
Login as a customer.
Add one or more products to cart.
Open checkout.jsp.
Fill first name, last name, address, email, and phone.
Submit checkout.
Expected result is thankyou.jsp.
Expected database result is a new row in order table, new rows in order_detail table, and reduced product stock.
Test order history.
Login as the same customer after placing an order.
Open order-history.
Expected result is order-history.jsp with order id, total, date, and detail button.
Click detail.
Expected result is order-detail.jsp with ordered products, quantity, price, and total.
Test seller order management.
Login as a seller account that owns ordered products.
Open order-management.
Expected result is order-management.jsp with ordered product details for that seller.
Static JSP pages
about.jsp is a static about page.
contact.jsp is a static contact page and its form does not save data because it posts to hash only.
thankyou.jsp is shown after checkout succeeds.


File purpose list
Database.java opens the MySQL connection.
AccountDao.java reads, creates, and updates account records.
CategoryDao.java reads categories and product counts per category.
ProductDao.java reads, searches, creates, updates, soft deletes, paginates, and reduces product stock.
OrderDao.java creates orders, creates order details, reads customer order history, reads order detail history, and reads seller order details.
Account.java is the account model used for login, signup, profile, seller, and admin checks.
Category.java is the category model used in shop and product forms.
Product.java is the product model used in shop, product detail, cart, and seller product management.
CartProduct.java is the cart line item model containing product, quantity, and price.
Order.java is the order model containing account, cart products, total, and date.
HomeControl.java handles the root page and forwards to index.jsp.
ShopControl.java handles shop listing and forwards to shop.jsp.
CategoryControl.java handles product filtering by category and forwards to shop.jsp.
SearchControl.java handles product search and forwards to shop.jsp.
ProductDetail.java handles product detail pages and forwards to product-detail.jsp.
CartControl.java handles adding and removing products in the session cart.
CheckoutControl.java handles checkout submission and creates database orders.
LoginControl.java handles login form submission and remember me cookie login.
LogoutControl.java clears login session and remember me cookies.
RegisterControl.java handles account signup.
ProfileControl.java handles viewing and updating logged in user profile data.
ProductManagementControl.java handles seller product management page data.
AddProductControl.java handles seller product creation.
EditProductControl.java handles seller product edit page and update submission.
RemoveProductControl.java soft deletes seller products.
OrderHistoryControl.java handles customer order history.
orderDetailControl.java handles one order detail page.
OrderManagementControl.java handles seller order management.
index.jsp is the home page.
shop.jsp displays products, categories, and pagination.
product-detail.jsp displays one product and the add to cart form.
cart.jsp displays session cart products and total.
checkout.jsp displays checkout and customer detail form.
login.jsp displays the login form.
register.jsp displays the signup form.
profile-page.jsp displays and updates account profile fields.
product-management.jsp displays seller products and add product modal.
edit-product.jsp displays the edit product form.
order-history.jsp displays customer orders.
order-detail.jsp displays products inside one order.
order-management.jsp displays seller order product details.
about.jsp displays about content.
contact.jsp displays contact content.
thankyou.jsp displays the successful checkout message.
templates head.jsp contains shared head markup.
templates header.jsp contains shared site navigation.
templates footer.jsp contains shared footer markup.
templates scripts.jsp contains shared JavaScript imports.
templates featured-products.jsp contains reusable featured product display.
templates collections-section.jsp contains reusable collection category display.
